# PianoX

**An interactive piano application built with Flutter and Dart.**

PianoX is a software development project exploring how digital technology can make piano playing and learning more accessible.

The long-term vision is to develop an interactive piano environment that supports beginners as they progress towards advanced piano skills.

## Project Status

Early development.

## Planned Features

- Interactive virtual piano.
- Full 88-key piano keyboard.
- Computer keyboard input.
- Mouse interaction.
- Realistic audio playback.
- Multiple octaves.
- Music learning exercises.
- Structured lessons and progress tracking.

## Technology Stack

- Flutter
- Dart
- Visual Studio Code
- Git and GitHub

## Development Roadmap

1. Establish the application architecture.
2. Develop the virtual piano interface.
3. Implement keyboard and mouse interaction.
4. Integrate the audio engine.
5. Implement all 88 piano keys.
6. Develop learning features.
7. Test, optimise and release.

## Getting Started

Ensure Flutter is installed.

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate into the project directory:

```bash
cd pianox
```

Install dependencies:

```bash
flutter pub get
```

Run the Windows application:

```bash
flutter run -d windows
```

## Vision

PianoX aims to combine an accessible digital piano with a structured music-learning environment.
